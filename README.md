# Сайт Вероники Сухаревой

Статический сайт-визитка для GitHub Pages.

Основная страница: `index.html`.

Посетители сайта могут только просматривать опубликованную страницу. Изменять исходники могут только пользователи с правами записи в репозиторий.

## GitHub Pages

Для первой публикации: `Settings` -> `Pages` -> `Deploy from a branch` -> `main` -> `/(root)` -> `Save`.

После этого изменения в ветке `main` будут автоматически появляться на сайте.
