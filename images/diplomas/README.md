# Как добавить диплом на сайт

1. Загрузите изображение диплома в эту папку: `images/diplomas/`.
2. Лучше использовать понятное имя латиницей без пробелов, например `magistratura-2025.jpg` или `supervision-certificate.png`.
3. Откройте в корне репозитория файл `diplomas.js`.
4. Внутри массива `DIPLOMAS` добавьте строку вида:

```js
{ file: 'images/diplomas/magistratura-2025.jpg', title: 'Диплом магистра', note: 'Организационная психология, 2025' },
```

`title` и `note` можно менять или оставить пустыми. Ориентацию определять не нужно: горизонтальные документы автоматически занимают больше места на широком экране, вертикальные — обычную карточку. На телефоне все документы показываются в одну колонку.

Поддерживаются обычные изображения JPG, JPEG, PNG, WebP и AVIF. При нажатии на диплом посетитель открывает исходное изображение в полном размере.
